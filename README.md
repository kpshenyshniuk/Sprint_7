# Проект с автотестами

## 📌 Описание проекта
Этот проект представляет собой набор **автоматизированных тестов** для проверки API сервиса.  
Тесты написаны с использованием **pytest** и **requests**.

## 📂 Структура проекта
- **conftest.py** – файл с фикстурами для pytest.
- **data.py** – содержит тестовые данные для запросов.
- **helpers.py** – вспомогательные функции для работы с API.
- **tests/** – папка с тестами:
  - **test_create_courier.py** – тесты для создания курьера.
  - **test_login.py** – тесты для авторизации курьера.
  - **test_create_order.py** – тесты для создания заказа.
  - **test_get_list_orders.py** – тесты для получения списка заказов.

## 🛠 Используемые технологии и фреймворки
- **Python** – язык программирования.
- **Pytest** – фреймворк для тестирования.
- **Requests** – библиотека для HTTP-запросов.
- **Allure** – инструмент для генерации отчётов о тестировании.

## ✅ Какие проверки выполняются?
1. **Создание курьера (`test_create_courier.py`)**
   - Проверка успешного создания курьера.
   - Попытка создания курьера с уже существующим логином.
   - Проверка ответа API при нехватке обязательных полей.

2. **Авторизация курьера (`test_login.py`)**
   - Успешная авторизация с валидными данными.
   - Попытка входа с неверным паролем.
   - Попытка входа с несуществующим логином.

3. **Создание заказа (`test_create_order.py`)**
   - Успешное создание заказа.
   - Создание заказа без обязательных полей.

4. **Получение списка заказов (`test_get_list_orders.py`)**
   - Проверка, что API возвращает список заказов.
   - Проверка структуры ответа (наличие ключа `orders` и его формата).
